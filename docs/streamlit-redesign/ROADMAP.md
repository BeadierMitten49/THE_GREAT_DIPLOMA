# Roadmap переработки Streamlit UI

Цель: реализовать все экраны АИС «Ярко» в Streamlit строго по HTML-прототипам из `html_pages/`.

---

## Последовательность страниц

Порядок определён по принципу **зависимостей данных**:
- Справочники — базовые данные (сырьё, упаковка, продукция, заказчики, рецептуры)
- Склады — используют позиции из справочников
- Заказы — используют заказчиков и продукцию из справочников, остатки со складов
- Производственные задачи — привязаны к заказам, списывают сырьё со склада
- Отгрузки/Сборка — завершают задачи, списывают продукцию со склада готовой продукции
- Доставки — финальный шаг после отгрузки
- Дашборды — агрегируют данные из всех предыдущих модулей, поэтому идут последними

## Краткое описание каждой страницы

### SCR-001 — Вход
**7 состояний:** Default (поля пустые), Filled-active (поля заполнены, кнопка активна), Submitting (спиннер), Error-invalid (неверный логин/пароль), Error-deactivated (учётная запись деактивирована), Validation-empty (пустой submit), Locked (блокировка после 5 попыток).

### SCR-002 — Дашборд директора
**3 состояния:** Default, Empty (всё хорошо), Loading (скелетоны).
**6 карточек:** Критические остатки, Активные резервы, Просроченные задачи, Ближайшие доставки, Задачи на проверку, Уведомления.

### SCR-003 — Главная производства
**4 состояния:** Default-InProgress (задача в работе), Stopped (задача остановлена), Created (новая задача), Empty (задач нет).
Отображает **одну активную/новую задачу** + уведомления.

### SCR-004 — Дашборд склада
**2 состояния:** Default, Empty.
**4 карточки:** Ожидающие операции, Активные резервы, Критические остатки, Уведомления.

### SCR-005 — Главная доставки
**2 состояния:** Default, Empty.
Таблица доставок на сегодня (крупный шрифт) + уведомления.

### SCR-006 — Заказы
**9 состояний:** Default, Drawer-open (Сборка), Drawer-open (Производство), Empty, Empty-filtered, Loading, Error, Drawer-deleted, Role-Warehouse.
Список + боковая панель детали. Разное поведение для директора и склада.

### SCR-007 — Производственные задачи
Таблица задач с фильтрами + drawer детали. Директор видит все задачи, может управлять. Производство — только свои задачи.

### SCR-008 — Доставки
Таблица доставок + drawer + bulk-выделение строк (для директора). Статусы: Готов к выдаче, В пути, Завершено.

### SCR-009 — Отгрузки и Сборка
Таблица заказов в статусе «Сборка» + drawer с чеклистом продукции. Кнопка «Отгрузить» активируется только когда все позиции отмечены.

### SCR-010 — Склад сырья
Таблица партий сырья с остатками, порогами, сроками годности. Фильтр по критическим позициям. Кнопки «Приход» / «Списание».

### SCR-011 — Склад упаковки
Аналог склада сырья, но без сроков годности. Упрощённая таблица.

### SCR-012 — Склад готовой продукции
Партии готовой продукции с номерами (П-YY-MM-NN). Резервирование под заказы. Срок годности.

### SCR-015 — Справочники
Вкладки: Сырьё, Упаковка, Продукция, Рецептуры, Заказчики. Drawer для создания/редактирования.
