**Статус:** ⬜ Не начата

## Что реализуем

Страница входа — единственная страница приложения, доступная без авторизации.
После успешного входа сохраняем токены в `st.session_state` и делаем `st.rerun()`,
после чего `app.py` переключается на нужный дашборд по роли.

## 7 состояний из прототипа

| Состояние | Триггер | Что показываем |
|-----------|---------|----------------|
| **Default** | Открытие страницы | Поля пустые, кнопка «Войти» неактивна (серая) |
| **Filled-active** | Оба поля заполнены | Кнопка «Войти» становится активной (тёмная) |
| **Submitting** | Нажата «Войти» | Кнопка показывает спиннер + текст «Вход…» |
| **Error-invalid** | API → 401 | Красная рамка на полях + сообщение «Неверное имя пользователя или пароль» |
| **Error-deactivated** | API → 403 | Сообщение «Учётная запись деактивирована. Обратитесь к директору.» |
| **Validation-empty** | Submit при пустом поле | Красная рамка на пустом поле + подпись «Заполните это поле» |
| **Locked** | API → 429 | Блок-предупреждение «Вход временно заблокирован», без формы |

## Маппинг API → состояния

| HTTP-код | Значение | Состояние UI |
|----------|----------|--------------|
| 200 | Успех | Сохраняем токены → `st.rerun()` |
| 401 | Неверный логин/пароль | Error-invalid |
| 403 | Учётная запись деактивирована | Error-deactivated |
| 429 | Слишком много попыток | Locked |
| Нет связи | `httpx.RequestError` | Ошибка «Нет связи с сервером» |

**Эндпоинт:** `POST /auth/login` с телом `{"username": ..., "password": ...}`
**После успеха:** `GET /users/me` для получения `full_name`

## Что сохраняем в session_state

```python
st.session_state["tokens"]     = {"access_token": ..., "refresh_token": ...}
st.session_state["roles"]      = [...]        # из JWT payload
st.session_state["user_id"]    = int(sub)     # из JWT payload
st.session_state["user_info"]  = {"full_name": ...}  # из /users/me
```

## Ограничения Streamlit и решения

| HTML-поведение | Streamlit-решение |
|----------------|-------------------|
| Кнопка disabled пока поля пустые | CSS-инжекция: кнопка отображается серой через `pointer-events: none` + проверка после submit |
| Красная рамка на конкретном поле | CSS-инжекция через `st.markdown` с уникальным селектором |
| Иконка 👁 на поле пароля | Streamlit `type="password"` скрывает текст, переключение нативно не поддерживается — показываем без иконки |
| Спиннер на кнопке во время запроса | Streamlit показывает глобальный спиннер — достаточно |
| Карточка по центру 400px | `st.columns` + CSS `max-width` |
