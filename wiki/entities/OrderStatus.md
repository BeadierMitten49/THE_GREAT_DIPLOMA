# OrderStatus (Статус заказа)

Value object модуля заказов. `StrEnum` — сериализуется в строку.

## Значения

| Значение | Описание | UI-метка |
|----------|---------|----------|
| `created` | Создан, начальный статус | Создан |
| `production` | Ожидает производства продукта | Производство |
| `assembly` | Продукция на складе, кладовщик собирает заказ | Сборка |
| `delivery` | Заказ передан курьеру | Доставка |
| `completed` | Доставлен клиенту | Завершён |

## Диаграмма переходов

```
Создан → Производство → Сборка → Доставка → Завершён
Создан → Сборка ─────────────────┘
```

## Правила переходов

- `created → production` — директор, при нехватке продукции
- `created → assembly` — директор, при наличии продукции на складе
- `production → assembly` — директор, только когда все связанные задачи закрыты
- `assembly → delivery` — после создания доставки и отгрузки
- `delivery → completed` — водитель нажимает «Доставлено»
