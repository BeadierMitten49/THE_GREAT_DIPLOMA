# TaskType (Тип производственной задачи)

Value object модуля задач. `StrEnum` — сериализуется в строку.

## Значения

| Значение | Описание | UI-метка |
|----------|---------|----------|
| `stock_task` | Задача в запас — пополнение склада без привязки к заказу | В запас |
| `order_task` | Задача под заказ — привязана к конкретному заказу | Под заказ |

## Различия в поведении

| Аспект | stock_task | order_task |
|--------|-----------|------------|
| Поле `order_id` | None | Обязательно |
| Создание из UI задач | Да (единственный вариант) | Нет |
| Создание из UI заказов | Нет | Да (при переходе в «Производство») |
| При закрытии задачи | Продукция на склад | Продукция на склад + резерв под заказ |
