# АИС «Ярко»

Автоматизированная информационная система для управления производственным предприятием по **фасовке пищевого сырья**. Веб-приложение, разработанное в рамках ВКР по направлению 09.03.02 «Информационные системы и технологии».

## Назначение

Единая точка контроля для директора предприятия + рабочие инструменты для каждой роли сотрудников. Устраняет ручное управление «по памяти» и снижает критическую зависимость бизнеса от директора.

## Ключевые бизнес-цели

1. Актуальная картина остатков сырья, упаковки, продукции в любой момент
2. Автоматизация постановки и контроля производственных задач с расчётом сырья
3. Прозрачное управление заказами от создания до доставки
4. Делегирование операций сотрудникам с контролем через систему
5. Минимизация ошибок при планировании производства и отгрузке

## Архитектура (высокий уровень)

- **Тип**: веб-приложение (браузерный клиент)
- **Доступ**: через браузер по сети предприятия и/или интернет
- **Стек**: FastAPI + SQLAlchemy (async) + PostgreSQL + Alembic (open-source)
- **Развёртывание**: локальный сервер заказчика или VPS
- **Интеграция**: только [[telegram-notifications|Telegram Bot API]]

## Роли пользователей

Смотри [[rbac-roles]].

| Роль | Описание |
|------|----------|
| Директор | Полный доступ ко всем функциям |
| Сотрудник производства | Только свои производственные задачи |
| Сотрудник склада | Приход, расход, резерв, отгрузка |
| Сотрудник доставки | Выполнение назначенных доставок |

## Модули

- [[order-management|Заказы]] — создание, жизненный цикл, резервирование продукции
- [[production-tasks|Производственные задачи]] — постановка, контроль, отчёт сотрудника
- [[warehouse-management|Склад]] — сырьё, упаковка, готовая продукция, отгрузки
- [[delivery-module|Доставки]] — управление курьерами, статусы, отмена
- [[telegram-notifications|Уведомления]] — Telegram-бот, реестр событий
- Отчёты — только директор, просмотр в интерфейсе (без экспорта в MVP)
- Дашборд — персонализирован под роль

## Физический контекст

Склад и производство — одно помещение, разделено на зоны. Температурные зоны хранения (комнатная, холодильная, морозильная) фиксируются физически и **не учитываются системой**.
