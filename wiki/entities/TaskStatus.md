# TaskStatus (Статус производственной задачи)

Value object модуля задач. `StrEnum` — сериализуется в строку.

## Значения

| Значение | Описание | UI-метка |
|----------|---------|----------|
| `created` | Создана, ожидает принятия исполнителем | Создана |
| `in_progress` | В работе | В работе |
| `stopped` | Остановлена (с причиной) | Остановлена |
| `completed` | Завершена, ожидает проверки директором | Завершена |
| `closed` | Закрыта директором, ушла в отчёты | Закрыта |

## Диаграмма переходов

```
Создана → В работе ⇄ Остановлена → Завершена → Закрыта
```

Задача может многократно переходить между «В работе» и «Остановлена».
